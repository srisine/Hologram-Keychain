# Hologram-Keychain

A mini pocket hologram display that uses Beam Splitter Cube to project the contents of a 0.96inch OLED appearing as hologram.

Features:
1. Cool 3D build in holograms: Built in holograms that can rotate or move in 3D.
2. Connect from phone: Using ESP32's built in wifi and bluetooth capability, we can control the hologram using our phone's
